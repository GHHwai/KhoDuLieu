Các công cụ sử dụng
Tài liệu này giới thiệu các công cụ được sử dụng trong quá trình thực
hiện bài tập/dự án xử lý dữ liệu.
1. Google Colab
Google Colab là môi trường lập trình Python trực tuyến chạy trên
trình duyệt. Công cụ cho phép viết và thực thi mã trong các notebook, xử
lý dữ liệu và xem kết quả mà không cần cài đặt Python đầy đủ trên máy
tính.
Mục đích sử dụng - Viết và chạy mã Python để xử lý, phân tích dữ
liệu. - Thử nghiệm thuật toán và kiểm tra kết quả theo từng bước. - Lưu
notebook trên Google Drive và chia sẻ khi cần.
Truy cập: https://colab.research.google.com/
Google Colab là công cụ trực tuyến nên không cần tải và cài đặt phần
mềm riêng. Người dùng cần đăng nhập tài khoản Google để lưu notebook
thuận tiện hơn.

2. MySQL
MySQL là hệ quản trị cơ sở dữ liệu quan hệ, dùng để lưu trữ, tổ
chức, truy vấn và quản lý dữ liệu bằng ngôn ngữ SQL.
Mục đích sử dụng - Tạo cơ sở dữ liệu và bảng để lưu trữ dữ liệu. -
Thực hiện các câu lệnh SQL như CREATE, INSERT, SELECT, UPDATE và
DELETE. - Nhập dữ liệu từ tệp CSV vào bảng để phục vụ việc truy vấn và
phân tích.
Phần mềm và liên kết tải
- MySQL Community Server -- máy chủ cơ sở dữ liệu MySQL: Tải tại
  trang chính thức
- MySQL Workbench -- giao diện đồ họa để thiết kế cơ sở dữ liệu,
  viết SQL và quản lý máy chủ: Tải tại trang chính
  thức
Khi cài đặt, hãy chọn phiên bản phù hợp với hệ điều hành đang sử dụng và
làm theo hướng dẫn trên trang chính thức.
