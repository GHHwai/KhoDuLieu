# Các công cụ sử dụng

Tài liệu này giới thiệu các công cụ được sử dụng trong quá trình thực hiện bài tập/dự án xử lý dữ liệu.

## 1. Google Colab

Google Colab là môi trường lập trình Python trực tuyến chạy trên trình duyệt. Công cụ cho phép viết và thực thi mã trong các notebook, xử lý dữ liệu và xem kết quả mà không cần cài đặt Python đầy đủ trên máy tính.

**Mục đích sử dụng:**
- Viết và chạy mã Python để xử lý, phân tích dữ liệu.
- Thử nghiệm thuật toán và kiểm tra kết quả theo từng bước.
- Lưu notebook trên Google Drive và chia sẻ khi cần.

**Truy cập:** [Google Colab](https://colab.research.google.com/)

> Google Colab là công cụ trực tuyến nên không cần tải và cài đặt phần mềm riêng. Người dùng cần đăng nhập tài khoản Google để lưu notebook thuận tiện hơn.

## 2. MySQL

MySQL là hệ quản trị cơ sở dữ liệu quan hệ, dùng để lưu trữ, tổ chức, truy vấn và quản lý dữ liệu bằng ngôn ngữ SQL.

**Mục đích sử dụng:**
- Tạo cơ sở dữ liệu và bảng để lưu trữ dữ liệu.
- Thực hiện các câu lệnh SQL như `CREATE`, `INSERT`, `SELECT`, `UPDATE` và `DELETE`.
- Nhập dữ liệu từ tệp CSV vào bảng để phục vụ việc truy vấn và phân tích.

**Phần mềm và liên kết tải:**
- **MySQL Community Server:** Máy chủ cơ sở dữ liệu MySQL. [Tải tại đây](https://dev.mysql.com/downloads/installer/)
- **MySQL Workbench:** Giao diện đồ họa để thiết kế cơ sở dữ liệu, viết SQL và quản lý máy chủ. [Tải tại đây](https://dev.mysql.com/downloads/installer/)

**Phiên bản sử dụng:**
- MySQL Server 8.0+
- MySQL Workbench 8.0+ CE

## 3. GitHub

GitHub là nền tảng lưu trữ mã nguồn trực tuyến dựa trên Git, hỗ trợ quản lý phiên bản, theo dõi các thay đổi trong dự án và cộng tác giữa các thành viên trong nhóm.

**Mục đích sử dụng:**
- Lưu trữ mã nguồn và các tệp liên quan đến dự án.
- Quản lý lịch sử thay đổi, giúp theo dõi và khôi phục các phiên bản khi cần.
- Chia sẻ mã nguồn và hỗ trợ làm việc nhóm.
- Lưu trữ tài liệu hướng dẫn sử dụng dự án thông qua các tệp Markdown như `README.md`.

**Liên kết dự án:** [KhoDuLieu trên GitHub](https://github.com/GHHwai/KhoDuLieu)

**Liên kết truy cập và tải công cụ:**
- **GitHub:** [Truy cập trang chủ](https://github.com/)
- **GitHub Desktop:** [Tải tại đây](https://desktop.github.com/)
- **Git:** [Tải tại đây](https://git-scm.com/downloads)

> GitHub có thể được sử dụng trực tiếp trên trình duyệt mà không cần cài đặt. Nếu muốn quản lý mã nguồn trên máy tính, người dùng có thể cài đặt Git hoặc GitHub Desktop.

## 4. Tóm tắt

| Công cụ | Vai trò chính |
|---|---|
| Google Colab | Viết và chạy Python trực tuyến để xử lý, phân tích dữ liệu. |
| MySQL | Lưu trữ, quản lý và truy vấn dữ liệu bằng SQL. |
| MySQL Workbench | Giao diện hỗ trợ kết nối và thao tác với MySQL. |
| GitHub | Lưu trữ mã nguồn, quản lý phiên bản và chia sẻ dự án. |
| Git / GitHub Desktop | Hỗ trợ quản lý mã nguồn và đồng bộ dự án trên máy tính. |
